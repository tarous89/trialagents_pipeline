# TrialAgents Pipeline

Standalone pipeline planning for biotech teams. Track programs, milestones, activities, decisions, deliverables, risks and changes in the browser, ChatGPT or Claude. Production target: `pipeline.trialagents.com`.

## Start here

- [Open the standalone design preview](preview/Pipeline.html) by downloading the HTML and opening it in a browser. It contains a fictional workspace and saves demo edits locally.
- [Product and implementation scope](docs/IMPLEMENTATION.md) covers the shared Render deployment, accounts, team billing, permissions, settings, audit history, custom views and assistant publishing.
- [Source and design map](docs/SOURCES.md) identifies the exact Platform and Intel revisions, source files, design fidelity checks and the boundary between the preview and production.
- [Approved Pipeline design](reference/Pipeline.html) is the original design handoff. [Platform Programs description](reference/platform/PROGRAMS.md), [package description](reference/platform/README.md) and [Platform HTML](reference/platform/programs.preview.html) preserve the related catalog baseline.

This repository starts with the scope and a design preview. Live team access, payments, email, assistant tools and production hosting are implementation milestones. The preview runs locally without credentials.
